1. Из чего складывается стоимость?
a) Анализ требований и подготовка структуры проекта.
b) Разработка Frontend на Next.js.
c) Разработка Backend на FastAPI.
d) Интеграция Frontend и Backend, работа с API.
e) Тестирование и исправление ошибок (QA).
f) Развертывание проекта на сервере и финальная настройка.
2. Этапы разработки и тестирования
a) Анализ и уточнение требований, формирование структуры проекта.
b) Подготовка архитектуры и основной структуры Frontend и Backend.
c) Разработка Frontend на Next.js.
d) Разработка Backend и API на FastAPI.
e) Подключение Frontend к Backend и интеграция API.
f) Проверка основных пользовательских сценариев и функционала.
g) Исправление выявленных ошибок и повторное тестирование.
h) Финальная настройка и развертывание проекта на сервере.
3. Стек технологий и архитектура
Frontend: Next.js
Backend: FastAPI (Python)
API: REST API
База данных: PostgreSQL
Контроль версий: Git
Развертывание: Linux-сервер
Архитектура проекта будет разделена на Frontend и Backend. Next.js будет отвечать за пользовательскую часть, а FastAPI — за серверную логику и API.
4. QA и безопасность
Контроль качества будет проводиться в процессе разработки и на финальном этапе.
Будет проверено:
основные пользовательские сценарии;
корректность работы API;
правильность обработки входных данных;
авторизация и права доступа;
обработка ошибок;
взаимодействие Frontend и Backend;
корректная работа интерфейса на основных разрешениях экранов.
5. Сроки выполнения проекта
1) Подготовка структуры проекта, backend-диаграмм и UI/UX-дизайна — 5 дней.
2) Разработка Backend, создание базы данных, реализация функций и API — 8 дней.
3) Разработка Frontend, создание страниц и дизайна, интеграция API с Frontend — 7 дней.
4) Полное QA-тестирование проекта, выявление и исправление ошибок — 9 дней.
5) Развертывание проекта на сервере и настройка параметров безопасности — 1 день.
